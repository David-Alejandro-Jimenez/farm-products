# Farm Products
Sitio web catálogo para una granja pequeña que está comenzando su negocio de venta de productos artesanales como quesos, yogures y más. Los clientes exploran los productos en la web y concretan sus pedidos directamente por WhatsApp.

## Contexto
Este proyecto fue desarrollado por encargo para una pequeña granja local. No es open source, pero el código es abierto con fines de aprendizaje y portafolio personal del desarrollador.

## Tecnologías
- HTML5
- CSS3
- JavaScript vanilla

```
farm-products/

├── assets/

```

## Flujo de trabajo
- `main` → código listo para producción
- `develop` → rama de integración
- `feature/*` → funcionalidades en desarrollo

## Convención de commits
| Prefijo | Uso |
|---|---|
| `feat:` | nueva sección o funcionalidad |
| `fix:` | corrección de errores |
| `style:` | cambios visuales o de CSS |
| `content:` | actualización de productos o textos |
| `docs:` | cambios en documentación |
